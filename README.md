## Процедура запуска автоматизированных тестов

### 1. **Требования**
Перед запуском автоматизированных тестов убедитесь, что:
- Установлена последняя версия **Android Studio**.
- Установлен **Android SDK**.
- Проект корректно собран и запускается.
- Установлены библиотеки для тестирования: **Espresso**, **UIAutomator**.
- Подключено тестируемое устройство или настроен эмулятор.

### 2. **Настройка окружения**
1. Откройте проект в **Android Studio**.
2. Убедитесь, что тестовый модуль правильно указан в `build.gradle`.
3. Проверьте, что устройство или эмулятор активны.
4. Выполните команду для сборки проекта:
   ```sh
   ./gradlew assembleDebug
   ```
5. Выполните команду для сборки тестов:
   ```sh
   ./gradlew assembleAndroidTest
   ```

### 3. **Запуск тестов из Android Studio**
1. Откройте вкладку **Run > Edit Configurations**.
2. Выберите конфигурацию **Android Instrumented Tests**.
3. Укажите тестовый класс или пакет.
4. Нажмите **Run**.

### 4. **Запуск тестов из командной строки**
Для запуска всех тестов используйте:
```sh
./gradlew connectedAndroidTest
```

### 5. **Анализ результатов тестирования**
- allure-results.zip  отчёт о результатах прогона тестов (Allure).
